# ECE535FinalProject
 MEMs Mouse HID device
 This is a Custom USB HID Device running on a STM32F407G-DISC1. It enumerates as a keyboard and a mouse. Reports are polled by the host every 5ms. The mouse cursor is controlled by the X, Y movements of the onboard LIS3DSH accelerometer and the mouse left click is controlled by reading the User Button GPIO value. The keyboard can generate a spacebar input based on a GPIO interrupt. This interrupt is fired by the LIS3DSH accelerometer in response to a single tap detection. The LIS3DSH has State Machine Registers which can be programmed with next/reset conditions using opcodes. These include timers and thresholds that can be combined for gesture detection. This project used various topics from the EC535 course including: working with ARM processors, using serial communication protocols (SPI, USB), interfacing with sensors (timing and resource management), interrupts (timing and resource management).
